# Adel Aloui

AI and software engineer in Algeria. I build local-first tools: macOS utilities in Swift, RAG systems and small ML experiments in Python.

### Projects

**[Lidward](https://github.com/alouiadel/lidward)**  
macOS menu-bar app that keeps the machine awake, including with the lid closed. Swift and AppKit.

**[whisper-realtime-echo](https://github.com/alouiadel/whisper-realtime-echo)**  
Real-time and file-based speech-to-text desktop app built on Whisper, with a Flet interface.

**[ragstead](https://github.com/alouiadel/ragstead)**  
Self-hosted RAG chat over your own documents, using Ollama, FastAPI and vanilla JS, with retrieval written from scratch.

**[ai-snake-game](https://github.com/alouiadel/ai-snake-game)**  
Snake trained with a deep Q-network in Pygame and PyTorch.
